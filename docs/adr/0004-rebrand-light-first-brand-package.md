# ADR-0004: Rebrand on an external brand package, light first, without the terminal aesthetic

- **Status:** Accepted
- **Date:** 2026-10-14

## Context

The site was dark-only, set in JetBrains Mono and IBM Plex Sans, and dressed as a terminal: a shell command over every page title (`❯ ls ./blog`), `//` before every section label, a dot grid behind everything, a blinking red cursor as the mark. Its tokens lived in `globals.css` and its mark was outlined from a font by a script in this repo.

Davide designed a personal brand that has to live in more places than this site (slides, social cards, a Slidev theme): a mark that draws a `d` and an `i` as a git graph tied with a red knot, a light ground, three typefaces, and three graphic elements (the marker, the tape, the rule). Keeping its values here would mean every other surface copies them and drifts.

## Decision

1. **The brand lives in its own repository**, [davideimola/brand](https://github.com/davideimola/brand), installed as `@davideimola/brand` (`github:davideimola/brand`, pinned by the lockfile). It owns the tokens (`tokens/tokens.json`, built to `dist/css/tokens.css` and a Tailwind v4 `@theme` mapping), the mark and wordmark geometry, every SVG and PNG, and the guidelines (`docs/brand.md`). `globals.css` imports `@davideimola/brand/tailwind.css` and adds only what is site-specific. Brand assets are copied into `public/brand/` and the favicon/apple icon by `pnpm brand:sync`; `scripts/generate-brand.py` and `brand:png` are retired.
2. **Light first, with a full dark theme.** Light (paper) is the default. Dark (night) follows `prefers-color-scheme`, and a toggle pins a choice per browser (`localStorage`, applied before first paint by an inline script in `<head>`). Print is always light: a print block in `globals.css` outranks the brand's system-preference block, which is otherwise more specific than its own print block.
3. **New type.** Schibsted Grotesk for titles and running text, IBM Plex Mono for code and metadata, Barlow Condensed bold for tape labels only, all via `next/font/google`. The image routes and the CV PDF use static TTFs from google/fonts in `public/fonts/` (Schibsted Grotesk's static weights are instances cut from the official variable file, because satori cannot read variable fonts).
4. **The terminal aesthetic is dropped site-wide.** No command labels, no `//` prefixes, no dot grid, no blinking cursor. Section and content-type labels are flat ink tapes; page titles are sans. `/terminal` (the interactive shell) and `/links` (the link-in-bio session) keep their terminal content as features, inside the new chrome.
5. **The red rule.** Akane red belongs to the knot and to one marker stroke per page. Links may turn red on hover and code keywords may be red; nothing else is red at rest: no red buttons, tapes, badges or borders.

## Consequences

- Changing a colour, a size or the mark is a change in the brand repo plus a dependency bump (and `pnpm brand:sync` for assets), never an edit here.
- Every token utility was renamed (`text-text-1` → `text-fg`, `bg-bg-card` → `bg-surface`, …). The old names no longer exist.
- `dark:` is available as a custom variant that matches whichever way the dark tokens became active, but components should rely on tokens and rarely need it.
- The newsletter email (`src/emails/`) still uses its own dark theme; it renders in mail clients, not on the site, and was left for a separate pass.
- `public/cv.pdf` is regenerated by CI (ADR-0003); with the new fonts it still fits one A4 sheet.
